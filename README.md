# wb_cars

## Sobre o Projeto

O **wb_cars** é um sistema web completo para gestão de oficinas, concessionárias e empresas do ramo automotivo. O objetivo é facilitar o controle de veículos, clientes, serviços, estoque, vendas e muito mais, tudo em um só lugar!

## Tecnologias Utilizadas

- **Java 8**
- **Maven**
- **JSF (JavaServer Faces)**
- **PrimeFaces**
- **PostgreSQL**

O sistema contará com autenticação de usuários (login) e será desenvolvido do zero, com código limpo, organizado e seguindo boas práticas.
